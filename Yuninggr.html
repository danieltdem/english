一、 過去簡單式動詞變化（Past Simple）

1. 規則動詞變化

✦ 一般直接加 -ed：
• work ➔ worked（工作）、cook ➔ cooked（烹飪、煮）

✦ 字尾有 e 直接加 -d：
• decide ➔ decided（決定）、arrive ➔ arrived（抵達）

✦ 子音 + y，去 y 加 -ied：
• study ➔ studied（研讀、學習）

✦ 短母音 + 單子音，重複字尾加 -ed：
• stop ➔ stopped（停止）

2. 不規則動詞變化（課本精選必背）

• make ➔ made（製作）  |  • lay ➔ laid（擺放餐桌）
• go ➔ went（去）      |  • come ➔ came（來）
• see ➔ saw（看見）    |  • find ➔ found（找到）
• get ➔ got（得到／到達） |  • have ➔ had（有／吃）
• feel ➔ felt（感覺）    |  • run ➔ ran（跑）
• break ➔ broke（損壞）   |  • put ➔ put（放置／撲滅；三態同形）

二、 動詞加 -ing 規則變化（Past Progressive / 過去進行式）

規則 1：一般動詞直接加 -ing

• work ➔ working（工作）
• play ➔ playing（玩耍／打球）
• listen ➔ listening（聆聽）
• talk ➔ talking（說話）

規則 2：字尾是不發音的 e，去 e 加 -ing

• make ➔ making（製作）
• drive ➔ driving（駕駛）
• prepare ➔ preparing（準備）
• live ➔ living（居住）
• write ➔ writing（寫信）
• skate ➔ skating（溜冰）

規則 3：短母音 + 單子音結尾，重複字尾加 -ing

• get ➔ getting（得到／準備）
• run ➔ running（跑步）
• sit ➔ sitting（坐著）
• swim ➔ swimming（游泳）
