📚 英文名詞 6 大單複數變化寶典

1. 規則一：一般名詞直接加 -s

最標準的規則，絕大多數英文名詞直接在單數後加 -s。
例如：egg ➔ eggs、bottle ➔ bottles、star ➔ stars、cat ➔ cats、dog ➔ dogs。

2. 規則二：字尾 -s, -sh, -ch, -x, -o 加 -es

當字尾發出「噝音」（-s, -sh, -ch, -x）或多數「子音 + o」時加 -es。
例如：bus ➔ buses、dish ➔ dishes、watch ➔ watches、box ➔ boxes、potato ➔ potatoes、tomato ➔ tomatoes。

3. -o 結尾特例：樂器、科技、簡稱只加 -s

樂器（piano）、科技（radio, video）、外來語簡稱（photo）或雙母音（zoo），只加 -s。
例如：piano ➔ pianos、radio ➔ radios、photo ➔ photos、video ➔ videos、zoo ➔ zoos。

4. 規則三：字尾 -y 的兩大陣營

✦ 【子音 + y】➔ 去 y 變 -ies：baby ➔ babies、party ➔ parties、puppy ➔ puppies、strawberry ➔ strawberries。
✦ 【母音 + y】➔ 直接加 -s：boy ➔ boys、toy ➔ toys、monkey ➔ monkeys、day ➔ days。

5. 規則四：字尾 -f 或 -fe 變身 -ves

字尾為 -f 或 -fe 時，將 -f / -fe 變成 -ves。
例如：leaf ➔ leaves、knife ➔ knives、shelf ➔ shelves、wolf ➔ wolves、life ➔ lives。

6. 規則五：不規則複數天王

內部母音音變或特殊形式，需直接熟記：
• man ➔ men、woman ➔ women、policeman ➔ policemen
• foot ➔ feet、tooth ➔ teeth、goose ➔ geese（oo 變 ee）
• child ➔ children、mouse ➔ mice
